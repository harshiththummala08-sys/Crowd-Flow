# CrowdFlow Data Provenance

CrowdFlow Round 3 uses a reproducible mock traffic simulator by default. Prototype outputs are simulation results, not real-world measurements.

| Dataset | Purpose | Source | License / Notes | Local path |
| --- | --- | --- | --- | --- |
| Synthetic emergency events | Demonstrate safe emergency signal transition | Generated by the app | Safe to redistribute | In memory |
| Mock traffic scenarios | Demo traffic, queues, congestion, fairness | Generated by scripts | Safe to redistribute | `data/sample/` |
| METR-LA | Optional prediction research dataset | Download with official/public instructions before use | Do not commit raw data | `data/raw/metr-la/` |
| OpenStreetMap | Optional network import | Use OSM APIs or extracts and follow ODbL attribution | Do not commit large extracts | `data/raw/osm/` |
| SUMO network | Optional simulator integration | Generated locally from a configured network | Keep generated bulk output out of git | `data/processed/sumo/` |

METR-LA is used only for historical traffic prediction development. It does not represent a local city deployment. The current application uses mock/SUMO-ready simulation for controllable hackathon scenarios.
